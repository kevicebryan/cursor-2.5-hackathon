# Pokemu — Cursor 2.5 Hackathon

Cultural artifact guessing game built live during the hackathon.

**Restore color. Reclaim memory. Become a Ranger.**

See [CLAUDE.md](./CLAUDE.md) for architecture, routes, and the incremental build plan.

## Quick start (after scaffold lands)

```bash
cp .env.example .env.local
# fill in Supabase, Stripe, Gemini keys
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
